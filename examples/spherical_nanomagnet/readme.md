# Spherical Nanomagnet Examples

This directory contains matrix-free micromagnetic examples for spherical Fe nanomagnets with different radii.

## Structure

Each particle radius is stored in a separate folder:

- `R8nm/`
- `R10nm/`
- `R12nm/`
- `R14nm/`
- `R20nm/`

Each folder contains:

- `sphere_fe.krn`: material parameters
- `sphere_fe.p2`: field sweep and minimizer settings
- `run_sph.sh`: script that generates the mesh and runs the simulation

The mesh and result files are not stored in the repository. They are generated when `run_sph.sh` is executed.

## Geometry

Each example represents a spherical Fe particle. The folder name gives the radius in nanometers.

For example:

- `R10nm` corresponds to a sphere with radius `10 nm`
- `R20nm` corresponds to a sphere with radius `20 nm`

The mesh is generated as an ellipsoid with equal extents in all three directions. The mesh length scale is defined in `sphere_fe.p2`:

```ini
[mesh]
size = 1.0e-9
```

Thus, mesh coordinates are interpreted in nanometers.

## Material

The material parameters are defined in `sphere_fe.krn`.

The column order is:

```text
theta phi K1 K2 Js A
```

For the present Fe-like setup:

- `K1 = 4.8e4 J/m^3`
- `Js = 2.13628 T`
- `A = 1.0e-11 J/m`

## Field Sweep

The hysteresis sweep is defined in `sphere_fe.p2`.

The default setup uses a slightly tilted field direction close to the `+z` direction and sweeps the applied field from positive to negative values.

## Run

Enter one radius folder and execute the run script:

```bash
cd R10nm
./run_sph.sh
```

The script first generates the tetrahedral mesh:

```bash
sphere_fe.npz
sphere_fe.vtu
```

It then runs the hysteresis simulation and writes the output files into the same folder.

## Notes

Generated output files such as `.vtu`, `.state.npz`, and `.dat` files are intentionally not included. They can be regenerated by running the corresponding `run_sph.sh` script.
